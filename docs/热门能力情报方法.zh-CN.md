# 包参谋能力情报方法

## 定位

能力情报是外部发现索引，不是代码仓库、应用商店或自动安装器。数据只包含公开名称、仓库、指标、许可证字段和包参谋推荐判断。

## 推荐分

推荐分综合：采用量、近期增长、GitHub 星标与 Fork、维护活跃度、官方来源、许可证清晰度、资料完整度和与包参谋能力方向的适配度。

约束：

- 最多 300 条；
- 单仓库最多 20 条，避免榜单被一个仓库占满；
- 归档或禁用仓库不进入；
- 所有安装均为人工审核；
- 推荐分不是用户评分、安全认证或质量承诺。

## 更新

GitHub Actions 每周一、周四复筛一次。更新任务只写入索引数据和中英文摘要，不向用户中心源安装任何 Skill。
