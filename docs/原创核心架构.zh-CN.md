# 包参谋 v1.0 原创核心架构

## 产品目标

把分散在不同 AI 软件中的 Skill 变成可理解、可评估、可编组、可验收的个人能力资产。系统不以“安装数量”作为价值，而是以中文可读性、真实连接、风险边界和持续可维护性作为判断标准。

## 方策五环

```text
本机中心源
   ↓ 识别
中文名称、用途与特点
   ↓ 中文化
方策分与静态风险
   ↓ 评估
Codex / Claude / Gemini / Cursor / 其他 AI
   ↓ 编组
重新扫描真实路径与连接模式
   ↓ 验收
可核验的个人能力资产
```

## 自有数据模型

`SkillAsset` 由本机实时生成，包含：

- 中文名称、英文名称、目录 ID；
- 中文/英文说明与主要用途；
- 特点标签、类别、文件数和内容哈希；
- 方策分、风险等级和静态风险信号；
- 真实截图可用性；
- 各 AI 工具连接模式与冲突状态。

应用不要求远端账户，不建立云端技能内容数据库。

## 方策分

总分 100：

| 维度 | 分值 | 判断 |
|---|---:|---|
| 结构 | 25 | `SKILL.md` 与 frontmatter 是否存在 |
| 理解 | 20 | 是否能形成可读说明 |
| 可移植 | 20 | 是否位于中心源并可受控连接 |
| 安全 | 20 | 静态风险信号分级 |
| 可核验 | 15 | 是否生成内容 SHA-256 |

方策分不是安全认证、质量承诺或用户评分。

## 文件安全

- Skill ID 只允许单层正常路径组件。
- 读取 `SKILL.md` 前检查路径必须仍在中心源内。
- `SKILL.md` 最大 512 KB。
- 预览只允许 PNG/JPG/WebP/GIF，单图最大 2 MB。
- 不执行 Skill 文档，不运行其中脚本。
- 不覆盖冲突目录。
- 断开时只移除可验证的受管链接或带标记副本。
