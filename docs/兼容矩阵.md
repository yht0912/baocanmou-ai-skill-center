# 兼容矩阵

定制版保留上游适配器并增加 ZCode，共 48 个内置适配器。下表列出当前个人工作台的主要目标；其他工具可在桌面端的「工具管理」中查看。

| AI 工具 | 全局入口 | 项目级入口 | 默认策略 |
|---|---|---|---|
| Codex | `~/.codex/skills` | `<project>/.agents/skills` | 软链接 |
| Claude Code | `~/.claude/skills` | `<project>/.claude/skills` | 软链接 |
| Hermes | `~/.hermes/skills` | `<project>/.hermes/skills` | 软链接 |
| Gemini CLI | `~/.gemini/skills` | `<project>/.agents/skills` | 软链接 |
| Cursor | `~/.cursor/skills` | `<project>/.agents/skills` | 软链接 |
| ZCode | `~/.zcode/skills` | `<project>/.zcode/skills` | 软链接 |
| OpenCode | `~/.config/opencode/skills` | `<project>/.agents/skills` | 软链接 |

## 同步策略

| 平台 | 首选 | 第二选择 | 最后退化 |
|---|---|---|---|
| macOS | 软链接 | — | 副本 |
| Linux | 软链接 | — | 副本 |
| Windows | 软链接 | 目录联接 | 副本 |

副本仅是兼容退化，会带来版本漂移可能。使用副本后，每次更新都要重新同步并做哈希对账。

## 兼容说明

- 「有入口路径」不代表目标 AI 当前版本一定会加载 Skill。
- 某些 AI 使用 `.agents/skills` 作为项目通用规范；这与本机的全局中心源同名，但作用域不同。
- Cline 的工具检出目录是 `.cline`，不会因中心源 `.agents` 存在而被误判为已安装。
- 自定义工具可配置其全局和项目级技能目录；添加前应先查阅该 AI 工具的当前官方规范。
