# 知识产权与原创边界

## 包参谋主张的范围

v1.0 当前源代码中的方策五环数据模型、中文用途解释规则、方策评分、信息卡片、工具编组与验收流程、界面与双语文档由包参谋维护并按实际创作内容主张相应著作权。

## 不主张的范围

- 用户安装的第三方 Skill；
- 能力情报索引指向的仓库、名称、描述和源码；
- React、Tauri 等通用依赖；
- 通用文件格式、事实数据和公开指标。

外部项目和依赖继续适用各自许可证与权利边界。
