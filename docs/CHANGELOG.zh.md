# 中文更新记录

## v1.1.0 · 2026-09-10

### 新增

- 新增“图像生成”独立分类，可按用途、特点与中英文标识搜索。
- 能力卡显示真实可视案例数，详情使用原创极简 2×2 画廊展示最多 4 张开发者案例。
- 多风格技能优先从不同风格目录取样，案例名同时显示“风格目录 / 文件名”，避免同名图片无法辨认。

### 真实性

- 案例不足 3 张时明示数量缺口，不使用占位图、通用图或其他技能图片补数。
- 预览扫描排除依赖、构建产物和 App 图标，单图上限为 4 MB，以覆盖开发者提供的高清风格案例。

## v1.0.0 · 2026-09-01

### 新增

- 包参谋原创「方策五环」核心。
- 194 个本机技能的中文名称、明确用途与特点解释。
- 用途与特点直接显示在卡片第一视觉层；真实截图只在详情补充。
- Codex、Claude Code 等 8 类 AI 工具的真实连接盘点。
- 中英文界面与本机可编辑中文说明。

### 重构

- 替换旧数据库、安装器、同步引擎和界面模块。
- 外部热门能力改为“只索引、不打包、不自动安装”。
- 权限和依赖收敛为本地治理所需的最小集合。

### 安全

- 新增路径包含校验、文件大小限制、非托管目标保护和静态风险提示。
