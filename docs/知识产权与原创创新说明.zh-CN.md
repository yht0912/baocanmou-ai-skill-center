## 1. 文件目的

本文用于清楚记录“包参谋 AI 技能中心”的原创成果、开源来源和使用边界，方便代码协作、版本发布、著作权留档与后续品牌管理。本文不把第三方成果表述为包参谋原创，也不构成专利、商标或软件著作权登记已经获批的证明。

## 2. 包参谋原创成果范围

在不影响第三方既有权利的前提下，包参谋原创或独立新增的成果主要包括：

1. **产品定位与信息架构**：将普通 Skill 管理器重构为“个人 AI 能力资产治理中心”，形成“能力选择—统一治理—工具编组—持续审计”的产品路径。
2. **「方策」视觉识别**：方格、路径节点与策略推进含义组成的图形标识，以及配套应用图标、品牌色、排版和极简“静默清单”界面语言。
3. **中文语义显示层**：在不修改英文 Skill ID、目录和调用契约的前提下，增加中文名称映射、分词回退、双语浏览与相应测试。
4. **跨 AI 中心源模型**：以 `~/.agents/skills` 作为唯一中心源，把 Codex、Claude Code 及其他 AI 工具作为受治理入口，避免多份技能长期漂移。
5. **本地优先安全方案**：现有技能登记、同源保护、非托管目标保护、可恢复隔离、断链识别、Git 来源与 SHA-256 审计等组合机制。
6. **包参谋专属交互与文案**：能力作战台、谋/术/鸣治理路径、工具编组、能力资产、风险提示等界面结构和中文表达。
7. **中英双语交付体系**：中文主文档、英文独立文档、知识产权边界、使用手册和公开贡献规范。

上述范围随 Git 提交、版本标签、设计文件和发布记录共同形成可追溯的创作证据。具体权利以实际创作内容和适用法律为准。
