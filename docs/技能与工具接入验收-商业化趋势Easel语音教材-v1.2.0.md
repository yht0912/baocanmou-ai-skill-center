## 3. 移动应用·付费转化

### 安装与规范

- Skill 版本：0.1.0。
- 6 个源文件，`quick_validate.py` 通过。
- 六个 AI 工具入口均指向共享中心源，没有复制多份可漂移的 Skill。

### 行为验收：高持续成本 App

测试输入：AI 图片 App 每任务持续成本 0.12 美元，典型用户每月 50 次；开发者考虑月费 1.99 美元、周费 0.99 美元、终身 9.99 美元且不限量。

计算结果：

- 典型月成本：6.00 美元。
- 月费方案在渠道费前已亏 4.01 美元。
- 0.99 美元/周折合每月约 4.29 美元，渠道费前仍亏约 1.71 美元。
- 9.99 美元终身收入在渠道费前只覆盖约 83 次任务，低于典型用户两个月用量。

验收结论：技能规则会拒绝“低价无限终身”，并要求改为有额度的订阅、积分包或分层用量，再结合留存、地区、渠道费和真实调用分布定价；不会保证收入或擅自修改线上价格。行为符合上游场景 D。

## 6. OmniVoice 多语种语音

### 安装与轻量测试

- 包版本：0.2.1。
- 干净 Python 3.14 虚拟环境，避免与系统包复用时出现的 OpenMP 重复加载。
- 安装版本：PyTorch 2.14.0、torchaudio 2.11.0、Transformers 5.17.0。
- `pip check` 无依赖冲突；源码编译、包导入、两个 CLI `--help` 通过。
- 中文/英文断句、末尾标点与 `RuleDurationEstimator` 载入通过。
- 16 kHz 到 24 kHz 的张量重采样通过，输出形状 `(1, 2400)`。
- 当前 Codex 进程中 `torch.backends.mps.is_available()` 为 `False`，真实推理只能尝试 CPU，不能把 Apple Silicon 写成已启用 MPS。

### 模型与真实音频

Hugging Face `k2-fsa/OmniVoice` 快照：`c5fdb5ccb189668d56333f77ba2629f4cd7535f4`，13 个文件，总大小 3,267,470,260 字节。其中主模型约 2.45 GB，音频 tokenizer 约 806 MB。

模型 13/13 个文件已完整下载，主模型 blob 的 SHA-256 与 Hugging Face LFS 标识一致：`730839316de585f4c8298ec0e1712efc10fb19c6fa4e36eb741cb8d51ebcf6aa`。

真实推理使用 CPU、`num_step=1`、目标时长 3 秒、关闭去噪和后处理，文本为“你好，这里是包参谋多语种语音能力测试。”，声音设计标签为“女，青年，中音调”。结果：

- 输出：`output/omnivoice/包参谋_OmniVoice_中文测试.wav`。
- 格式：PCM 16-bit，24 kHz，单声道，3.2 秒，153,644 字节。
- 波形：RMS `0.11598`，峰值 `0.5`，非零采样比例 `93.10%`。
- 文件 SHA-256：`2e0789e945985af2ad0eafb748425e5d7c7f1b4c364808097ea9aa2722fcda48`。
- 第一次尝试使用“成年女性，普通话，清晰自然”时，上游校验器因标签不在合法词表中主动拒绝；改用上游支持的“女，青年，中音调”后生成成功。

以上证明模型加载、中文输入、声音设计和 WAV 输出链路可用；技术检查不能替代主观听感，最终音色是否合适仍需人工播放确认。

包参谋原创适配 Skill：`omnivoice-tts`。仅支持用户本人、已获授权或权利清晰的参考声音；禁止冒充、诈骗和绕过声纹验证。
