# User Guide

The desktop app reads `~/.agents/skills` and supported AI-tool paths locally. Use the six views to review the command overview, local assets, external intelligence, tool routing, safety signals, and authorship boundary.

To distinguish similar Skills, read the primary use and up to three feature labels directly on each card. Open the detail view for Chinese interpretation, Fangce score, risk signals, original `SKILL.md`, connected tools, and a real screenshot only when the Skill provides one.

Chinese text can be corrected in the detail view. The app writes only to `~/.baocanmou/skill-center/translations.json`; it does not modify the original Skill.

A filesystem connection does not prove that an already-running AI session loaded the Skill. Restart the target tool or start a new task and perform a real minimal call.
