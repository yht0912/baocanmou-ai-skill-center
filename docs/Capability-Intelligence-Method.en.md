# BaoCanMou Capability Intelligence Method

Capability intelligence is an external discovery index, not a code repository, app store, or automatic installer. It stores public names, repositories, signals, license fields, and BaoCanMou recommendation judgments only.

The score combines adoption, recent momentum, GitHub stars and forks, maintenance, official-source confidence, license clarity, documentation, and BaoCanMou capability fit. It is not a user rating, security certification, or quality warranty.

The catalog is capped at 300 entries and 20 entries per repository. Archived or disabled repositories are excluded. GitHub Actions refreshes the index twice weekly without installing any Skill.
