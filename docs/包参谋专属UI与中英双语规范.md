# 包参谋专属 UI 与中英双语规范

## 产品定位

“包参谋技能中心”是个人使用的中文 AI 能力资产库，不是通用技能商店，也不是品牌展示页。界面采用“静默清单”方向：打开后先看到能力数量、搜索、治理状态和技能列表，降低日常查找与同步成本。

## 视觉标识

- 应用标志采用重新设计的“方策”：墨黑圆角方底、米白开放框架、战略黄决策点。它同时对应“包”的空间结构和“参谋落子”的动作。
- 主色为暖白 `#f7f6f2`、墨黑 `#20201c`、战略黄 `#e5b91e`；黄色占比保持克制，只出现在标志、主操作和选择状态。
- 主构图为浅色轻侧栏、平面资产概览和紧凑列表；搜索是首要工作入口。
- 列表视图只显示工具编组结论，逐工具开关进入卡片视图或详情页，避免兼容图标堆叠。
- 明确禁用：大面积深色展板、口号、策略路径、紫蓝 AI 渐变、通用玻璃拟态、三等分指标卡和卡片装饰竖线。

## 中英双语规则

1. 当技能名是英文时，界面第一行显示中文译名，第二行保留英文原名。
2. 中文译名与英文原同时参与搜索；按名称排序时以中文主名为准。
3. 当前中心库 185 个有效技能已全部建立精确中文名称映射。
4. 未来新技能若尚未收录精确译名，界面使用中文词素推导作为临时名，同时保留完整英文原名。
5. 不重命名技能目录，不改写 `SKILL.md` 中的原始 `name`、触发词和指令。中文是展示层，英文 ID 是兼容层。

## 为什么不直接翻译技能文件

Codex、Claude 和其他 AI 工具可能已经通过目录名、frontmatter `name`、英文触发词或脚本路径引用这些技能。直接重命名或整篇覆盖存在断链、触发失效和后续升级冲突风险。因此本项目采用“中文浏览＋英文兼容”的双层模型。

## 验收标准

- 中文搜索“标志”能找到 `logo-generator`，英文搜索 `logo-generator` 也能找到同一技能。
- 列表、卡片、详情、Git 候选、本地候选和导入页面使用同一套双语名称逻辑。
- 最小 `900 × 640` 窗口下，中文主名与英文 ID 不被互相覆盖，页面不出现横向滚动。
- “方策”标志在 16 px 导航尺寸、64 px Dock 尺寸和 512 px 安装包预览中仍能识别。
