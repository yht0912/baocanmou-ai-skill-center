# 兼容路径

| 用途 | 默认路径 | 行为 |
|---|---|---|
| 中心源 | `~/.agents/skills` | 唯一技能事实 |
| 中文校正 | `~/.baocanmou/skill-center/translations.json` | 只保存名称与说明 |
| Codex | `~/.codex/skills` | 受控连接 |
| Claude Code | `~/.claude/skills` | 受控连接 |
| Gemini CLI | `~/.gemini/skills` | 按需连接 |
| Cursor | `~/.cursor/skills` | 按需连接 |
| Hermes | `~/.hermes/skills` | 按需连接 |
| ZCode | `~/.zcode/skills` | 按需连接 |
| OpenCode | `~/.config/opencode/skills` | 按需连接 |
| Windsurf | `~/.windsurf/skills` | 按需连接 |

macOS/Linux 创建软链接。Windows 先尝试目录链接，权限不足时才复制，并写入 `.baocanmou-managed-copy` 标记。没有标记的目录一律视为非托管冲突。
