# 兼容路径

## 全局路径

| 用途 | 默认路径 | 定位 |
|---|---|---|
| 中心技能源 | `~/.agents/skills` | 唯一可维护的技能事实 |
| 隔离回收区 | `~/.agents/backups/skill-center-trash` | 桌面端可恢复删除 |
| Codex | `~/.codex/skills` | 优先软链接到中心源 |
| Claude Code | `~/.claude/skills` | 优先软链接到中心源 |
| Hermes | `~/.hermes/skills` | 按需连接 |
| Gemini CLI | `~/.gemini/skills` | 按需连接 |
| Cursor | `~/.cursor/skills` | 按需连接 |
| ZCode | `~/.zcode/skills` | 本地中文版新增的适配器 |
| OpenCode | `~/.config/opencode/skills` | 按需连接 |

Windows 优先使用目录联接，无权限时才退化为副本。macOS/Linux 优先使用软链接。

## 项目级路径

项目内的 `.agents/skills`、`.claude/skills`、`.codex/skills` 等只是当前项目入口。技能本体仍保留在中心源，不在多个项目中各维护一份。

## 链接验收

1. 入口存在，且不是断链。
2. `realpath` 或等价路径解析后指向对应中心技能目录。
3. `SKILL.md` 可读，frontmatter 中的 `name` 与目录名一致。
4. 对需运行时依赖的技能，从目标 AI 工具执行一次真实最小调用。
