# Security Policy / 安全策略

## Supported Versions

Only the latest code on the `main` branch is supported.

## Reporting a Vulnerability

If you discover a security vulnerability (e.g., arbitrary file read/write, path traversal, permission bypass, information disclosure, or command injection), please do not disclose it in a public issue.

Please report it through GitHub Private Vulnerability Reporting on this repository's **Security → Advisories** page. Do not include secrets, private Skill content, or unredacted local paths in the report.

We will acknowledge a reproducible report and coordinate disclosure through the private advisory. Public issues containing sensitive details may be edited or closed after the information is preserved privately.

## 中文

仅支持 `main` 分支的最新版本。

如发现任意文件读写、路径穿越、权限绕过、信息泄露或命令注入等安全问题，请通过本仓库 **Security → Advisories** 的私密漏洞报告入口提交，不要直接发布公开 Issue。

报告中不要附带 Token、密码、Cookie、私人 Skill 内容或未经脱敏的本机路径。确认问题可复现后，我们会在私密 Advisory 中协调修复与披露。
