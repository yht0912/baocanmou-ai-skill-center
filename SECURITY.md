# 安全政策 / Security Policy

请不要在公开 Issue 中提交密码、Token、Cookie、私钥、个人目录内容或未脱敏截图。安全问题可通过 GitHub Security Advisory 私密报告。

The application is local-first, but a Skill may still contain risky instructions or scripts. Static signals are only review prompts. Users must confirm source, license, dependencies, network access, write scope, and authorization before execution.

Only the latest `1.x` release receives security fixes.
