# Contributing

Contributions for open exchange and learning are welcome.

1. State the user problem and verifiable outcome first.
2. Add tests for new product logic.
3. Do not commit third-party Skill source, secrets, cookies, browser profiles, or private user content.
4. Preserve source and license facts; never present external work as BaoCanMou authorship.
5. Run `npm run check` and use semantic commit messages.

The BaoCanMou name, `www.bcmsj.com`, and graphic mark are not licensed as brands with the MIT code.
