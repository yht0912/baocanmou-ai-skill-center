# BaoCanMou v1.0 Design Contract

The interface uses a quiet command-center language: warm paper, near-black structure, one strategy-yellow accent, compact data typography, and clear information hierarchy.

## Original visual rules

- One memorable device: the square strategy path with five nodes.
- No decorative gradients, oversized glass effects, or generic dashboard ornament.
- Chinese name is primary; English ID is a small compatibility label.
- Every capability card puts purpose, features, score, risk, and tool state in the first information layer.
- Real screenshots are supplementary detail only; never fabricate an outcome image when none exists.
- External intelligence must say “index only, not bundled.”

## Responsive contract

- 1240 × 790 is the reference desktop viewport.
- At 1080 px the sidebar collapses to icons and asset cards use two columns.
- At 760 px content becomes a single column and the detail drawer fills the available panel.
